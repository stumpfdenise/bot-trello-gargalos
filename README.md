# 🤖 Bot Gargalos

Projeto de Iniciação Científica voltado ao desenvolvimento de uma ferramenta automatizada para identificação de gargalos e impedimentos em fluxos Kanban utilizando integração com a API do Trello.

## 🚀 Objetivo

A proposta do projeto é auxiliar equipes ágeis e agilistas na identificação de tarefas paradas, possíveis sobrecargas e impedimentos técnicos, reduzindo fadiga de cobrança e aumentando a visibilidade do fluxo de trabalho.

Além da identificação automática de gargalos, o sistema também permite registrar observações e impedimentos relacionados às tarefas, trazendo mais contexto humano ao acompanhamento do fluxo.

## 📊 Dashboard

O sistema conta com uma dashboard visual para acompanhamento do fluxo de tarefas e identificação de possíveis gargalos em tempo real.

---

## 🔒 Segurança

As credenciais da API e informações sensíveis são armazenadas localmente através de variáveis de ambiente (`.env`) e não são compartilhadas no repositório.
